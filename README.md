# ArchitecturePlanner

[在线规划台](https://thu-mem.github.io/ArchitecturePlanner/) · [React Flow](https://reactflow.dev/) · [Excalidraw](https://github.com/excalidraw/excalidraw)

基于 AI-MEM 架构的可编辑规划台，支持模块、技术组件、依赖与分工。模块和组件各支持一位主 owner、多位协作 owner。Owner 仅是规划信息，不授予账号或权限。

## 使用与发布

1. 页面默认展示已发布规划；如需继续浏览器中的修改，点击「恢复本地草稿」。不需要时点击「删除本地草稿」，会直接删除此浏览器保存的草稿并关闭提示，刷新后不再出现；不影响已发布规划。之后主动编辑会生成新的本地草稿。
2. 编辑模块或组件后「应用」，可导入、导出 JSON 备份。此时修改仍只在当前浏览器。
3. 点击「提交到 GitHub」→「复制并前往 GitHub」，在原生编辑器全选粘贴，再 Commit 或提 PR。无需向规划台提供 Token。
4. 变更进入主分支并通过检查后，Pages 自动发布；审核、权限与冲突处理由 GitHub 和维护者负责。

复制失败时可手动复制页面中的 JSON 或导出文件，不会自动跳转。复制和打开 GitHub 不代表已提交，返回后仍可恢复草稿。

**规划与分工会进入公开仓库，导出文件也包含人员信息。只填写获授权公开的昵称与规划内容，不要加入凭据、邮箱或其他个人信息。**

## 架构画布

顶部 Tab 的激活状态独立保存在当前浏览器本地，刷新后恢复上次打开的视图；首次访问或保存的 Tab 已失效时展示「业务架构」，不影响规划草稿或画布内容。

顶部第三个 Tab「架构画布」是独立的自由绘图工作区，不改变业务架构、技术快照或分工 JSON。

在架构画布中直接按 `Ctrl+V`（macOS 为 `⌘V`）：剪贴板图片会作为可移动、缩放的图片插入；普通文字会创建可编辑文本框，保留换行。插入位置优先使用画布上最后的鼠标位置，否则使用可见绘制区域中央。输入框和正在编辑的文本仍正常粘贴，不会额外生成画布元素；原生图形复制粘贴保持不变。粘贴支持撤销、自动保存、文件备份与 PNG 导出；图片单张上限 20 MiB，转换为静态透明 PNG，最长边不超过 4096 像素。

技术架构默认展示「部署域与用户入口」，在现有组件上以两个虚线框区分主服务器与 GPU 服务器；「现场已部署」仍只显示此前核实的运行资源。新增目标依据 2026-11-04 用户规划，均标为待接入，未进行新的 SSH 核验：

- 主服务器运行 Kubernetes，作为统一入口与跳板。GPU 主动通过 SSH 反向隧道（`-R`）将模型端口映射到主服务器；请求经主服务器 API 代理与映射端口到达 GPU 上的 TTS、视频生成和建模服务。GPU 不被当作第二个 Kubernetes 节点；不公开主机地址、凭据或未确认端口。宿主机回环与 Pod 网络的实际接入方式待实施。
- 官网 Home page 项目位于 `/`，承担 Navigation，进入 `/app` 的浏览器端 Agent loop。规划通过 PWA 安装到支持的手机或电脑；IndexedDB 分层保存会话、记忆、任务等结构化业务数据，Cache Storage 独立缓存应用壳和静态资源。不代表本规划台已实现 PWA，不承诺离线推理、云同步或永久保存。

- 使用内置工具绘制矩形、椭圆、箭头、线条、文字和自由画笔，支持移动、缩放、绑定箭头、撤销与重做。默认使用清晰的直线样式，也可调整笔画风格。
- 选中一个方块、椭圆、菱形或 Logo，四周显示连接锚点；从锚点拖到另一个组件即可连线，无需切换箭头工具。默认创建起点无箭头、终点有箭头的原生直角连线，两端绑定组件，移动组件时自动跟随。拖到空白或按 Esc 取消，不生成残留；锁定或多选时不显示锚点。锚点获得键盘焦点后按 Enter 可选择终点创建连线。
- 选中箭头后，下方快捷设置可切换实线／虚线／点线，以及单向终点／双向／无箭头；原生属性面板仍可继续调整线宽、颜色、箭头形状和直线／曲线／直角类型。连线和样式变化都支持撤销、备份、刷新恢复与 PNG 导出。
- 打开「技术 Logo」，按分类浏览或使用中英文名称、缩写和关键词搜索，再点击或拖入 SVG 素材；手机使用点击插入。现有 **207 项素材：135 个品牌 Logo、72 个阿里云服务示意图**，覆盖云平台、容器、数据库、消息、可观测、开发交付、AI 和安全。素材保留宽高比，可移动、缩放，并与框图组合。
- 「导出 PNG」导出全部图形（不只是当前视口），保留画布背景与 Logo，最长边不超过 4096 像素。空画布不可导出。
- 「下载画布文件」保存可继续编辑的 `.excalidraw` 文件；「导入画布文件」可恢复，已有内容时必须确认替换。导入上限 20 MiB。

内容仅在当前浏览器自动保存，使用独立键 `architecture-planner.drawing.v1`，**不随规划提交、不自动上传，也不跨设备同步**。清理浏览器数据会丢失草稿，请下载文件备份。存储失败会明确提示，仍可编辑并下载备份；损坏草稿不会被静默覆盖，支持先下载原始内容再明确舍弃。画布按需加载，字体和技术 Logo 从本站提供，不接入协作服务器或 AI 服务。

选型先比较许可与功能：采用 [Excalidraw React 组件](https://docs.excalidraw.com/docs/@excalidraw/excalidraw/integration)（MIT，支持 React 19），复用成熟的自由绘图、图片与 [PNG 导出 API](https://docs.excalidraw.com/docs/@excalidraw/excalidraw/api/utils/export)。React Flow（MIT）继续承担现有节点拓扑，不重复开发自由画笔；[tldraw 当前 SDK](https://tldraw.dev/community/license) 的生产使用需要许可证密钥，未选用。

### SVG 素材来源与边界

品牌素材选自 GitHub 上的 [SVG Logos](https://github.com/gilbarbara/logos) 和 [Simple Icons](https://github.com/simple-icons/simple-icons)（均为 CC0-1.0），保留原始品牌造型。新增素材固定上游 commit，清单、分类和搜索词见 [`drawing-icon-library.json`](src/drawing-icon-library.json)，新增文件的 SHA-256 见 [`drawing-icon-checksums.json`](src/drawing-icon-checksums.json)。维护者可用 `node scripts/sync-drawing-icons.mjs` 重新获取固定版本；使用已登录的 `gh`，不会在用户打开页面时访问 GitHub 或第三方图标 CDN。预览图片按需加载，不将全部 SVG 塞入 JavaScript。

阿里云类别包括 Alibaba Cloud、Qwen、Ant Design 品牌，以及 ECS、ACK、ACR、FC、OSS、NAS、RDS、PolarDB、VPC、负载均衡、网关、SLS、ARMS、RAM、KMS、PAI、百炼等 72 个常见产品的**服务示意图**。后者由现有 Lucide 图形与产品缩写组合，透明背景、无外部图片或字体依赖，**不是阿里云官方产品图标，也不是完整产品目录**；素材按钮及分类说明会明确标记。原始 Logo 自带的有色造型属于品牌本身，不另加白色底板。

研究过 [alibaba-sa/cloud-icons](https://github.com/alibaba-sa/cloud-icons)、[mcsrainbow/alibaba-cloud-icons](https://github.com/mcsrainbow/alibaba-cloud-icons) 和 [jinxiao/alibaba-cloud-icons](https://github.com/jinxiao/alibaba-cloud-icons)。前两者未提供明确的图形再分发许可，后者的 MIT 明确排除第三方图形，因此没有将这些官方服务图形复制进本仓库。取得适当授权后可替换对应示意图，不应把仓库代码许可当成图形许可。品牌与产品名仍归各自权利人；图标不代表已部署或获得品牌背书。

### Excalidraw 已接能力与后续优化

当前依赖的是标准 `@excalidraw/excalidraw` React 编辑器，不是完整的 excalidraw.com 网站或 Excalidraw+ 服务。组件没有 fork 或删改绘图内核，通过 ESM 引用导出，整个画布工作区延迟加载；实际产物由 Vite 拆包，不等于每个 npm 文件都进入首次下载。关闭入口并不保证相关代码完全从产物中消失，字体插件也会发布依赖包自带的全部字体文件。原生选择、多选、分组、对齐、图层、画框、自由画笔、文字、图片和绑定箭头由编辑器提供。本站隐藏重复的文件/导出菜单、主题切换和 AI 入口，提供自己的保存、导入、PNG、Logo 面板及拖拽连接锚点；字体从本站提供，协作与云存储后端没有接入。

后续按实际收益建议优先做：

| 优先级 | 优化 | 接入边界 |
|---|---|---|
| 高 | 可编辑 SVG、透明背景／选区／分辨率可选的导出 | 复用 `exportToSvg`、`exportToBlob`，补本站导出设置与测试 |
| 高 | 私有组件库与架构模板 | 持久化原生 library items，复用整组“服务＋标签＋箭头”，不只单个 Logo |
| 高 | 从业务／技术架构生成可编辑草图 | 将现有 ELK 坐标与拓扑转为原生 elements；只生成副本，不反写规划 |
| 中 | 多画稿、版本恢复、自动保存节流 | 目前每次变更会同步序列化单一草稿；大图宜转 IndexedDB、防抖并在离开时可靠落盘 |
| 后续 | 跨设备同步与多人协作 | 组件有 API 但不是开关即用，需另建鉴权、持久化、冲突合并与隐私边界 |

上表是后续建议，除 SVG 素材库扩充外并未在本轮启用这些功能。Mermaid 或 AI 生成也需要额外解析／模型服务，不会因安装编辑器而自动获得。

## 数据与边界

[规划 JSON](src/seed-plan.json) 是正式数据源，分工与账号映射由维护者人工核对更新。账号映射仍待确认；空白认领保持未分配，不推断协作或组件负责人。

箭头表示上游 → 下游，保留依赖反馈环。业务架构默认展示全部依赖，由 ELK 按拓扑自动排列模块、减少交叉并绕开节点；相对选中模块，蓝线表示上游、橙线表示下游，其他依赖为灰线。首次打开和「重新布局」在所有屏幕上保留至少 75% 的可读缩放，不再为了容纳全图自动缩成一团；超出画布时以当前模块（未选中则首个模块）为起点平移浏览，屏幕尺寸不改变节点坐标和间距。需要总览时主动点击「适应全图」，仍可自由缩放。可取消「全部连线」聚焦当前模块。自动布局仅改变当前视图，不写入草稿；手动拖动后保存当前模块坐标，拖动相关的线改用动态折线。模块详情支持双向跳转。

成员和分工使用 DiceBear 首字母头像，在浏览器本地生成，不向外部头像服务发送信息，也不改变规划 JSON。已映射账号使用获授权的姓名拼音缩写；公开映射仅保存 GitHub 昵称与不重复的两字母缩写，不包含真实姓名、完整拼音或源文档链接。未映射的成员沿用显示昵称生成头像。
选中画布模块后，直接上游卡片显示深蓝色光晕，直接下游显示淡黄色光晕，兼具两种关系的反馈模块显示双色光晕；其余卡片与无关连线淡化，但仍可点击。工具栏图例与「全部连线」同排，窄屏可横向滚动。
再次点击已选卡片或点击画布空白处可取消选中，恢复全部卡片与连线的正常显示；键盘聚焦卡片后用 Enter / 空格切换选中，Esc 取消选中。未选中时不限制为当前模块连线。
团队成员列表中，已确认的 GitHub 昵称可点击并在新标签页打开主页；手动添加的普通姓名不推断账号。

顶部紧凑 banner 合并 ArchitecturePlanner、当前视图与已分配数量；技术架构的「Kubernetes · 服务与数据」也在同一标题行。其下用一行文字 Tab 依次切换「业务架构」「技术架构」「架构画布」「分工清单」「技术组件」「团队成员」「原始架构」，窄屏横向滚动，不再保留左侧导航占位或常驻发布／删除状态。筛选改为紧凑横向工具栏，画布铺至浏览器底部，详情独立滚动；窄屏详情位于画布下方。规划名称可在 banner 悬停查看，未提交编辑保留提示，草稿恢复、删除和错误处理不受影响。

业务架构选中模块时，右侧当前 owner、直接上游 owner、直接下游 owner 同步显示青色、深蓝色、淡黄色提示；兼具关系的人员保留全部标签，其余人员淡化。高亮不勾选协作 owner、不修改分工；依赖按钮同时展示对应模块的 owner，可留在业务画布继续追踪。

「技术架构」复用原项目现状页面、React Flow 与共享 ELK 布局／连线，覆盖 Kubernetes 基础设施、入口、身份、服务、存储和独立业务。默认展示运行现场，可切换全部组件／源码与待接入，支持缩放、适应全图与双向关系导航；此图只读，不写入业务规划 JSON。

技术事实依据 AI-MEM 的 `server/deploy`、`server/services` 与 **2026-11-02 22:08 UTC+08:00 的实际 SSH 只读复核**。现场为单节点 Kubernetes，19 个 Pod 全部 Running 且容器就绪。MEM-AI Deployment 1/1、Service 有 1 个就绪端点，已配置 PostgreSQL，数据库侧可见连接。图中实线展示「模型网关 → 网关 PostgreSQL 逻辑库 → PostgreSQL 共享实例 → postgres-data 20Gi 本地持久卷」；Keycloak 与网关共用实例，但使用不同逻辑库及数据库用户名，未审计 SQL 授权。网关另外保留「/data → mem-ai-data 1Gi 本地卷」，不是 PostgreSQL 主数据目录。三个 PVC（含 etcd 5Gi）均 Bound 至 local-path 节点本地 PV，不代表跨节点高可用或已有备份。

证书管理、服务发现、资源指标和集群网络均为**现场已运行**，不是规划：cert-manager 的 controller、cainjector、webhook 各 1/1；CoreDNS 2/2；metrics-server 1/1 且指标 API Available；Calico node 与 controllers 各 1/1。默认详情直接列出核对证据。当前没有 `Certificate` 资源，不能据此认定业务证书已由 cert-manager 签发。hub-api、事件服务、Redis、MinIO、ClickHouse、MCP、案例应用与 LLMWiki 本次集群未见，不推断其他主机的状态。MySQL／Redis 旧模板不是网关线上依赖。实线表示现场资源／配置关系，虚线表示源码／模板，点线表示待接入，**均不等于模型推理、登录、历史数据迁移或备份恢复的端到端验收**。

快照仅公开脱敏职责与状态，不含服务器地址、私有域名、Secret、环境变量值、人员实名或原始运维输出；不是实时监控，不自动改变规划状态。原始架构仍只读，规划台本身不接入 SSO，也不连接服务器、数据库或 Kubernetes API。

部署可通过 `VITE_GITHUB_PARTICIPANTS` 补充获授权公开的 GitHub 昵称，配置格式见[参与者合并逻辑](src/participants.ts)。按稳定账号 ID 合并，不重置已有分工；配置会进入公开页面，不能用于保存秘密。
